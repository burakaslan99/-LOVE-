## ✨ Özellikler

- **🎨 Modern Dark UI & Glassmorphism:** Derin obsidyen arka plan (`#09090b`), canlı neon orblar (fuşya, mor, cyan) ve pürüzsüz mikro-animasyonlar.
- **⚡ 3 Aşamalı Akıcı Deneyim:**
  1. **Hero Bölümü:** `@` Instagram kullanıcı adı girişi ve tek tıkla kurban seçimi (`@delulu_prenses`, `@gymbro_furkan`, `@entel_feridun_official` vb.).
  2. **Sahte Yapay Zeka Simülasyonu:** Dönen radar vizüalizörü, ilerleme çubuğu (%0 ➔ %100) ve terminal ajan logları.
     - *Ajan Alfa: Estetik ve vibe kontrolü yapılıyor...*
     - *Ajan Beta: Takipçi/Takip edilen ego oranı hesaplanıyor...*
     - *Ajan Gamma: Bio red flag'leri taranıyor...*
     - *Ajan Omega: Friendzone ihtimali dengeleniyor...*
  3. **Sonuçlar & Röntgen:** Animasyonlu dairesel skor sayacı, rozetler, 3 Kırmızı Bayrak (Red Flag), 2 Yeşil Bayrak (Green Flag), Yapay Zeka Kararı ve tek tıkla kopyalanabilen AI Rizz DM önerisi.
- **🔊 Dahili Web Audio API Sentezleyici:** Harici ses dosyasına ihtiyaç duymadan siber radar bip'leri ve başarı zili (Navbar'dan kapatılıp açılabilir).
- **📸 Instagram Story Paylaşım Kartı:** 9:16 formatında hazır paylaşım önizleme modalı.
- **📱 %100 Duyarlı (Responsive):** Mobil ve masaüstü tüm ekranlarda kusursuz uyum.

## 🚀 Kurulum ve Çalıştırma

Herhangi bir sunucu veya paket yöneticisi kurmana gerek yoktur. Uygulama tamamen bağımsız tek bir HTML dosyasından oluşur:

1. Bu depoyu klonla veya indir:
   ```bash
   git clone https://github.com/KULLANICI_ADIN/percent-love.git
   cd percent-love
   ```
2. `index.html` dosyasına çift tıklayarak doğrudan tarayıcında aç!

---

## 🌐 GitHub Pages ile Ücretsiz Canlıya Alma

1. Depoyu GitHub'a yükle (`git push`).
2. GitHub'da deponun **Settings > Pages** sekmesine git.
3. **Build and deployment > Branch** kısmından `main` (veya `master`) dalını ve `/root` seçeneğini seçip **Save** de.
4. Birkaç saniye içinde `https://kullanici_adin.github.io/percent-love` adresinde canlıya alınacaktır!
